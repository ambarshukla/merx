About this data

Where this series actually comes from — the publisher, the request that fetches it, the files kept as evidence, and the terms it is published under. None of it is written out by hand: it is read from the dataset's contract and from the raw zone's manifest, so it cannot drift away from what the pipeline really does.

How this site treats the data

Only the published layer is shown: data that passed the publish gate. Tier 1 series are published only when no critical check fails; other tiers are published marked warn, with the failing checks named beside the badge.

As known on rebuilds a series exactly as it stood on that date, from every version in the history. Before this project began downloading (2026-10-15), versions come from dated copies in the Internet Archive's Wayback Machine, counted from the archive's capture time: an upper bound on when they were public.

Every download is kept, unedited, and everything downstream is rebuilt from those files. Nothing here is endorsed by any of the publishers named. The full record of each source's terms, and of the sources deliberately not used, is in the project's PROVENANCE document.

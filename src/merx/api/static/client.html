About this data

Only the published layer is shown here: data that passed the publish gate. Tier 1 series are published only when no critical check fails; other tiers are published marked warn.

As known on rebuilds the series exactly as it stood on that date, from every version in the history. Before this project began downloading (2026-10-15), versions come from dated copies in the Internet Archive's Wayback Machine, counted from the archive's capture time: an upper bound on when they were public.

All data is from public sources (U.S. EIA, U.S. CFTC). See the project's PROVENANCE document.

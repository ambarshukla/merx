EIA publishes the same daily spot prices in two places: a spreadsheet download and an API. merx takes both, compares them value by value (a reconciliation), and keeps every past version of the spreadsheet. Where both channels have a date, their values agree almost everywhere; what differs is which dates exist. Between May and October 2026 the spreadsheets lost thousands of older prices that the API still serves. Source: U.S. Energy Information Administration (EIA), public domain; past copies via the Internet Archive's Wayback Machine.

Gaps in the spreadsheet line are dates it no longer has. Each tick in the rows under the chart is one date in that class.
